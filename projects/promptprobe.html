PromptProbe

Find out if your chatbot obeys the attacker instead of you.

LLM security Prompt injection Python Open source

01 What it does

PromptProbe is a small, dependency-light CLI that fires a battery of prompt-injection payloads at any HTTP chatbot or LLM endpoint and tells you which ones actually worked.

It ships 25 adversarial payloads across instruction override, system prompt leaks, jailbreak roleplay and encoding bypasses. Verdicts come from a canary, so they are evidence, not vibes.

It works with Ollama, OpenAI-compatible APIs, or a custom chatbot described in about ten lines of JSON. Secrets stay out of the config through $ENV_VAR expansion in URLs and headers.

Every run ends in a machine-readable JSON report with the full prompts and replies, ready for triage and proof-of-concept.

02 How it works

Each payload tells the model to print a unique random marker, the canary. What comes back decides the verdict:

  • VULNERABLE, the canary is in the reply. The injection worked.
  • LIKELY, no canary, but the model complied instead of refusing.
  • NOT_VULNERABLE, the model refused or ignored the injection.

Payloads are plain JSON, so adding your own takes a minute. --demo launches a vulnerable mock and a hardened mock, so you can see the tool work with no API key at all.

03 Usage

No API key needed for the demo:

git clone https://github.com/skibidin4than/PromptProbe.git
cd PromptProbe
pip install -r requirements.txt
python3 promptprobe.py --demo

Useful flags: --list shows the payloads, --retries retries flaky targets, --severity filters by severity and adds a severity breakdown to the summary.

04 Responsible use

Only test systems you are authorized to test. A VULNERABLE verdict is a lead, not a report — validate it with a manual proof-of-concept before reporting anything.
